# Keybindings

`SUPER` = Windows/Meta key.

## Shell panels

| Keybind | Action |
|---|---|
| `SUPER + Space` | App Launcher |
| `SUPER + S` | Settings |
| `SUPER + N` | Notification Center |
| `SUPER + D` | Dashboard |
| `SUPER + ,` | Quick Settings |
| `SUPER + SHIFT + Q` | Power Menu |

## Applications

| Keybind | Action |
|---|---|
| `SUPER + Return` | Terminal (kitty) |
| `SUPER + E` | Files (Nautilus) |
| `SUPER + B` | Browser (Firefox) |
| `SUPER + C` | Code editor (VS Code) |

## Window management

| Keybind | Action |
|---|---|
| `SUPER + Q` | Close window |
| `SUPER + F` | Fullscreen |
| `SUPER + SHIFT + F` | Fake fullscreen |
| `SUPER + V` | Toggle floating |
| `SUPER + P` | Pseudotile |
| `SUPER + J` | Toggle split direction |
| `SUPER + G` | Toggle group |

## Focus

| Keybind | Action |
|---|---|
| `SUPER + Arrow keys` | Move focus |
| `SUPER + H/L/K/J` | Move focus (vim) |

## Move windows

| Keybind | Action |
|---|---|
| `SUPER + SHIFT + Arrow keys` | Move window |
| `SUPER + SHIFT + H/L/K/J` | Move window (vim) |

## Workspaces

| Keybind | Action |
|---|---|
| `SUPER + 1-9` | Switch to workspace |
| `SUPER + SHIFT + 1-9` | Move window to workspace |
| `SUPER + [ / ]` | Previous/next workspace |
| `SUPER + scroll` | Scroll through workspaces |
| `SUPER + -` | Scratchpad toggle |
| `SUPER + SHIFT + -` | Send to scratchpad |

## Screenshots

| Keybind | Action |
|---|---|
| `Print` | Screenshot region → clipboard |
| `SUPER + Print` | Screenshot screen → clipboard |
| `SUPER + SHIFT + S` | Screenshot region → file |

## Media

| Keybind | Action |
|---|---|
| `XF86AudioRaiseVolume` | Volume +5% |
| `XF86AudioLowerVolume` | Volume -5% |
| `XF86AudioMute` | Toggle mute |
| `XF86AudioPlay` | Play/Pause |
| `XF86AudioNext` | Next track |
| `XF86AudioPrev` | Previous track |
| `XF86MonBrightnessUp` | Brightness +5% |
| `XF86MonBrightnessDown` | Brightness -5% |

## System

| Keybind | Action |
|---|---|
| `SUPER + SHIFT + R` | Reload Hyprland |
| `SUPER + CTRL + R` | Reload Quickshell |

## Mouse

| Binding | Action |
|---|---|
| `SUPER + LMB drag` | Move window |
| `SUPER + RMB drag` | Resize window |
